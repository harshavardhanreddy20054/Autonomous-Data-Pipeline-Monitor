# Autonomous Data Pipeline Monitor - Setup & Run Guide

## Project Overview
Full-stack data validation and anomaly detection system with React frontend and FastAPI backend.

---

## Prerequisites

- Python 3.8+
- Node.js 16+
- npm or yarn

---

## Project Structure

```
team/
├── main.py                 # FastAPI backend server
├── requirements.txt        # Python dependencies
├── uploads/               # Uploaded CSV files (auto-created)
├── pipeline_alert.md      # Generated report (auto-created)
└── frontend/
    ├── package.json       # Node dependencies
    ├── vite.config.js     # Vite configuration
    └── src/
        ├── components/    # React components
        ├── pages/         # Page components
        └── index.css      # Global styles
```

## Backend Setup

### 1. Install Python Dependencies

```bash
cd "d:\Capgemani\Primary Track-Data Validation\Practice\Agenitic AI\team"
pip install -r requirements.txt
```

### 2. Set Environment Variables (Optional)

Create a `.env` file in the project root:

```
GEMINI_API_KEY=your_api_key_here
```

Note: The backend works without the Gemini API key for basic validation.

### 3. Run the Backend Server

```bash
cd "d:\Capgemani\Primary Track-Data Validation\Practice\Agenitic AI\team"
python main.py
```

The backend will start at: `http://localhost:8000`

Available endpoints:
- POST `/upload` - Upload CSV file for analysis
- GET `/download` - Download generated markdown report
- GET `/health` - Health check

## Troubleshooting

### CORS Errors
- Ensure backend is running before frontend
- Backend allows origins: `localhost:5173`, `localhost:5174`

### Port Already in Use
- Frontend will auto-switch to next available port (e.g., 5174)
- Backend runs fixed on port 8000

### Module Not Found Errors
```bash
# Reinstall Python dependencies
pip install -r requirements.txt --force-reinstall

# Reinstall Node dependencies
cd frontend
rm -rf node_modules
npm install
```
